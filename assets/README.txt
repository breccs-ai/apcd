APCD Website, Assets folder
============================

Logos
-----

The APCD brand logos live in:

    assets/APCD/logo-dark.png   ← Logo on a BLACK background.
                                  Used on DARK surfaces (nav bar, footer,
                                  dark sections).

    assets/APCD/logo-light.png  ← Logo on a WHITE background.
                                  Used on LIGHT surfaces (About page
                                  "Who We Are", favicon).

Usage
-----

The site automatically picks the variant that contrasts best with each
surface. If you swap the logos, keep the same filenames.

If a logo file is missing, the navigation will gracefully fall back to a
gold circle with the letter "A".
